# فرمون — داشبورد قیمت پراید و پژو ۴۰۵

یک سایت استاتیک فارسی و راست‌به‌چپ برای دیدن، فیلترکردن و مقایسهٔ قیمت نمونه‌های مرجع بازار پراید و پژو ۴۰۵.

> **نسخهٔ داده:** ۲۵ شهریور ۱۴۰۵
>
> قیمت‌ها به **تومان** هستند و هر ردیف به یک نمونه با سال، کارکرد و وضعیت بدنهٔ مشخص اشاره می‌کند؛ بنابراین قیمت قطعی خرید یا فروش نیست.

## امکانات

- کاتالوگ ۲۵ نمونه از تیپ‌های پراید و پژو ۴۰۵
- جست‌وجو، فیلتر خانواده / وضعیت / بازه قیمت و مرتب‌سازی
- بازهٔ قیمت، نمودار روند هفت بررسی و صفحهٔ جزئیات هر نمونه
- مقایسهٔ دو مدل کنار هم
- ماشین‌حساب برآورد اولیه با توجه به کارکرد، بدنه، بیمه و سلامت فنی
- ذخیرهٔ علاقه‌مندی‌ها در مرورگر
- حالت روشن / تیره و طراحی واکنش‌گرا برای موبایل
- بدون بک‌اند، دیتابیس یا وابستگی JavaScript؛ مناسب GitHub Pages

## اجرای محلی

چون پروژه کاملاً استاتیک است، کافی است `index.html` را باز کنید. برای تجربهٔ نزدیک‌تر به انتشار می‌توانید در پوشهٔ پروژه اجرا کنید:

```bash
python3 -m http.server 8000
```

بعد `http://localhost:8000` را باز کنید.

## انتشار در GitHub Pages

فایل workflow در [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) آماده است و با هر push روی شاخهٔ فعلی یا `main` سایت را منتشر می‌کند.

اگر برای اولین بار است که Pages را فعال می‌کنید:

1. در GitHub به **Settings → Pages** همین مخزن بروید.
2. در بخش **Build and deployment**، گزینهٔ **Source** را روی **GitHub Actions** بگذارید.
3. به تب **Actions** بروید و اجرای workflow «انتشار در GitHub Pages» را تأیید یا دوباره اجرا کنید.
4. پس از پایان موفق، آدرس سایت معمولاً این است: `https://namanimous.github.io/name/`

هیچ هاست یا سرویس دیگری لازم نیست.

## ساختار پروژه

```text
.
├── index.html                    # ساختار و محتوای فارسی سایت
├── styles.css                    # طراحی واکنش‌گرا، حالت تیره و انیمیشن‌ها
├── app.js                        # داده‌ها و تمام تعامل‌ها
├── assets/favicon.svg
├── .nojekyll
└── .github/workflows/deploy-pages.yml
```

## منابع و روش داده

داده‌های نمونه در ابتدای [`app.js`](app.js) ثبت شده‌اند. برای هر خودرو نام و لینک منبع کنار جزئیات همان خودرو نمایش داده می‌شود. منابع این نسخه شامل صفحات قیمت/آگهی عمومی باما، همراه مکانیک، دیوار و گزارش‌های بازار هستند.

برای به‌روزرسانی قیمت‌ها، مقدارهای `price`، `low`، `high`، `history` و مشخصات نمونهٔ مربوط را در آرایهٔ `cars` تغییر دهید. همهٔ قیمت‌ها برحسب **میلیون تومان** نگه‌داری می‌شوند.

## سلب مسئولیت

قیمت بازار به شهر، رنگ، کارکرد واقعی، وضعیت شاسی و بدنه، سلامت فنی، بیمه، تجهیزات و شرایط معامله وابسته است. پیش از هر معامله، بازدید حضوری و کارشناسی فنی/بدنه انجام دهید.
